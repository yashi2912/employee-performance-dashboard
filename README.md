# 📊 Employee Performance Dashboard - Excel Project

### 🚀 Project Overview
Built an interactive Employee Performance Dashboard to track and analyze employee productivity, achievement, and quality across regions, departments, and time. Converted raw data from PostgreSQL/pgAdmin into actionable insights.

- Avg. Productivity by Department (Donut Chart)

- Avg. Achievement by State (Map Chart)

### ⚙️ Features
- Fully dynamic with slicers for Region, Performance Status, and Department
- KPI cards with conditional formatting
- Data cleaning & transformation

### 🛠️ Tools & Technologies
- MS Excel (Advanced)
- Pivot Tables & Pivot Charts
- Slicers & Timelines
- PostgreSQL / pgAdmin (Data Extraction)
- Data Visualization & Storytelling
